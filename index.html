Problem Statement

Naive Cosine Search Failure

Dense embeddings fail when queries contain exact product numbers, legal article citations, or technical keys. Pure vector search returns semantic neighbors while missing critical lexical matches, resulting in high context hallucination rates.

System Design

Two-Stage Hybrid Retrieval

Engineered parallel sparse (BM25 Okapi) and dense (Qdrant ANN) searches merged via Reciprocal Rank Fusion (k=60). The fused candidate set passes through a lightweight cross-encoder re-ranker before injecting context into the prompt payload.

Hardware Bottleneck

The 32GB GPU Wall

Whole-slide images (WSI) in histopathology exceed 100,000 x 80,000 pixels. Naive multimodal models require enterprise A100/H100 80GB clusters to process full embeddings without running out of CUDA memory.

Implemented adaptive tile-based patch extraction with CNN feature vector caching. Compressed redundant intermediate representations using statistical dimensionality reduction and selective multi-head attention pooling.

02 // DECISION TELEMETRY

Engineering Mindset: Measured Trade-offs

Systems engineering is about understanding the systemic penalty of every design choice. No state-of-the-art dogmatism.

Retrieval Accuracy vs. Latency SLA

+40ms Penalty

Adding a Stage-2 Cross-Encoder introduces a ~40ms overhead compared to raw ANN dot-product retrieval. For legal, financial, and policy enterprise search, factual document precision directly eliminates downstream LLM hallucinations.

Design Decision: Accepted (+40ms preserves 99.4% precision)

Retrieval Depth vs. Context Noise

RRF K=60

Retrieving Top-5 directly often misses crucial nuances scattered across disparate paragraphs. Retrieving Top-20 into the LLM context dilutes attention. Instead: Retrieve Top-60 via RRF, cross-encode to Top-5 before generation.

Design Decision: Overfetch + Re-rank > Shallow Retrieval

Chunk Boundary vs. Semantic Integrity

+25% Index Size

Strict 512-token chunk boundaries split sentences, table headers, and conditional clauses down the middle. Implementing a 20% sliding token overlap incurs a 25% larger vector index but completely eliminates context fracture.

Design Decision: Preserve semantic continuity over RAM

Embedding Dimensionality vs. Serving Budget

3.8x QPS Gain

Defaulting to 1536-dimensional embeddings creates severe network transfer and vector memory bloat. 384-dimensional compact embeddings paired with cross-encoders deliver 3.8x higher queries per second at 75% reduced memory footprints.

Design Decision: 384-d + Re-ranker out-benchmarks 1536-d
