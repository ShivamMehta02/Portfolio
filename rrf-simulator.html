Reciprocal Rank Fusion Simulator

Hybrid retrieval runs keyword search (BM25) and semantic search (vectors) side by side, then merges the two ranked lists. RRF fuses them using only rank positions, so incompatible score scales don't matter. Reorder either list, tune k and the weights, and watch the fused top-K update.

RRF(d)= Σr ∈ R wr / (k + rankr(d)) rank starts at 1 · docs missing from a list contribute 0

        The fusion step from the production retriever.

        def rrf(ranked_lists, weights, k=60, top_k=5):
    scores = defaultdict(float)   # hash map
    for docs, w in zip(ranked_lists, weights):
        for rank, doc_id in enumerate(docs, 1):
            scores[doc_id] += w / (k + rank)   # O(1)
    return heapq.nlargest(top_k, scores.items(),
                          key=lambda x: x[1])
